What this document is

The event site's mockups: each screen of the wireframes in the site's colour and type, with stand-in pictures, the site's generated pictures of each kind of event and a drawn skyline where the film goes, and numbered placeholder events, Event 1, Event 2 and so on, in place of real listings. None of the pictures shows a real event. A style page comes first, then the seven desktop screens with numbered notes beside them, then the phone. They were drawn from the wireframes on 16 November 2026 by Claude through Claude Code at the portal lead's direction, as the sprint's disclosure records, and they replace the first version of 11 November, which was stills of the live site; the change log says why. The PDF is the document; this page is its cover.

What it contains

Three parts, as the cover lists them:

  1. Style. The default palette, Clinic White, with each colour's value; the two families, Jura and Inter, at the sizes the screens use; and the components every screen is built from: buttons, chips and tags, fields, the listing row and the stand-in pictures.
  2. Desktop, 1440. Home, Calendar, Event page, Saved, For organizers, Post an event and Interests, each naming the wireframe page it follows.
  3. Phone, 390. Home with the Menu open, and the Calendar.
